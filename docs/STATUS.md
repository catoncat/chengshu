## 3. 状态怎么使用

- `TODO`：尚未按该任务完成实现与验证。
- `IN_PROGRESS`：正在执行，写明负责人/分支、已经完成的小步骤。
- `BLOCKED`：记录具体缺失的权限、环境、外部条件或前置任务，以及可继续的独立工作。不能只写“工具不行”。
- `DONE`：任务要求的实现、测试、证据与文档已齐全。仅有代码、PR 或一个通过的单测不够。

验收项另用 PASS / FAIL / BLOCKED / NOT_RUN / NOT_APPLICABLE。测试没跑不能算 PASS。B04 的研究任务可以以明确的失败实验和降级决策完成，但必须写出“动态网页后台捕获未上线”，不能偷换成果含义。

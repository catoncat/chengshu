# 原型验证与交付边界

日期：2026-09-09。

## 1. 本轮成果

- 三个交互方向的方案与取舍：拼合牌桌、叠卡炼金、流转剧场。
- 推荐组合的完整体验剧本：口袋 / 造物桌 / 工坊，卡面规则、配方改编、权限披露、部分失败、手机与动效。
- 单文件 `prototype.html`：包含样式、图形、示例与交互，不需要安装依赖；没有外部脚本、字体或接口请求。
- 可复现的 `check_prototype.py`：本轮浏览器行为与截图检查的脚本。它是原型验证，不是 Android 产品测试。

代码仅放在本设计目录。没有更改 Android、服务端转换、版本、签名、构建发布配置；没有创建线上演示站，没有发布 APK，没有合并本设计 PR。

## 3. 浏览器验证

本轮使用容器内 Chromium + Playwright，直接向空白页面装入实际 HTML（`set_content`）进行交互。没有连接用户 Mac。

环境的浏览器导航策略阻止了本地 file URL 和 localhost URL；没有更改或关闭该策略。因此：本轮验证的是浏览器中的页面布局和交互，**不是通过真实 URL 打开或真实 origin 下的跨刷新 localStorage 持久化验收**。

26 项检查通过：

| 组别 | 实际检查 |
| --- | --- |
| 基础配方 | 初始配方可运行；默认运行产生示例预览且不冒充交接回执；截图路径；零中间步骤路径 |
| 组合规则 | 更换为不相容来源会阻止运行；显式修复；撤销恢复之前的状态；不相容能力解释原因且不插入；按钮前移后移导致的兼容变化 |
| 结果与停止 | 双去向中一处失败仍保留另一处；单支重试不改成功结果；停止后没有晚到结果 |
| 示例导出 | 浏览器实际触发 `.txt` 示例文本下载，不宣称生成 EPUB |
| 社区与披露 | 联网能力插入前提示；明确选择只加入示例；社区作者标注虚构；外部去向说明；试配载入可编辑副本 |
| 配方收藏 | 当前会话收藏可见；自定义名称进行转义；浏览器拒绝存储时有明确提示 |
| 键盘与动效 | Escape 关闭面板；手动减少动效；系统减少动效时卡牌动画关闭 |
| 页面布局 | 390px 与 320px 下无页面级横向溢出 |
| 运行健康 | 本轮捕获零页面 JS 异常；零外部网络请求 |

检查生成了桌面造物桌、桌面工坊、手机造物桌、手机口袋、部分成功状态的实际页面截图。已目视检查桌面/手机主界面的排版；这些截图不是 AI 生成的概念画。

**没有验证：** 真机 Android / iOS 浏览器、真实 TalkBack/VoiceOver、所有浏览器的 local file 行为、真实持久存储跨刷新、正式插件执行、真实 OCR/录音/翻译、真实笔记/阅读器交接、生产级后台恢复。未做这些验证不影响把它作为设计原型交付，但不得称为生产功能已完成。

## 5. 怎样打开与复验

用户体验：保存 `prototype.html`，用允许运行本地 HTML 的现代浏览器打开。页面全部使用固定示例；浏览器限制本地存储时，会提示仅本次有效。GitHub 文件页显示源码，不是已部署的网站。

开发复验：在已经配置 Python、Playwright 与 Chromium 的测试环境执行同目录 `check_prototype.py`。脚本通过 `set_content` 检查交互，默认把报告与截图放入临时输出目录，不改产品代码。真实 URL/跨刷新存储应另设普通 origin 的测试，不能用内存 mock 冒充完成。

## 6. 下一轮优先补什么

先验证系统分享进入口袋的完整手机路径，再做可拖放但不依赖拖放的摆牌与子配方收起。正式产品应以口袋为日常入口；本轮为了评审默认进入造物桌。

不要先写插件运行底座再问用户如何组合。不要为追求卡牌感牺牲快速使用、真实数据去向、失败恢复与减少动效。先观察不熟悉项目的人能否自行完成 README 中的试用顺序。
